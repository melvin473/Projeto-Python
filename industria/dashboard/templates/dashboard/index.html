Plataforma de Monitoramento Preditivo

Banco de Dados MFPT

📚 Guia do Usuário

Esta plataforma é um Sistema Especialista em Manutenção Preditiva, projetado para monitorar, diagnosticar e analisar a saúde mecânica de ativos rotativos (motores elétricos e rolamentos). O motor matemático do sistema foi validado utilizando a base de dados internacional do MFPT (Machinery Failure Prevention Technology), focando na identificação precoce de falhas em rolamentos de esferas.

⏱️ 1. Aba: Monitoramento em Tempo Real (API)

Exibe os dados armazenados em um banco de dados SQLite. O banco de dados é alimentado por uma API REST.

  • Velocidade RMS: Métrica global que indica a energia de vibração da máquina, com as indicações de cores (Zonas Verde/Normal, Amarela/Alerta e Vermelha/Crítico) baseadas na norma internacional ISO 10816-3
  • Kurtosis: Indicador estatístico de sensibilidade a impactos agudos. Essencial para identificar o início de descascamento ou trincas em pistas de rolamento, onde o RMS ainda não se alterou.
  • Skewness: Mede a assimetria do sinal em relação à média zero. Alterações abruptas indicam falta de uniformidade ou forças unidirecionais agindo no ativo.
  • Gráfico de Tendência: Permite visualizar a evolução temporal do ativo para traçar o tempo de vida útil restante antes de uma falha.

🔬 2. Aba: Análise de Diagnóstico Avançado (arquivo .mat)

Utilize esta aba para analisar o sinal mecânico através do upload de um arquivo binário bruto estruturado (.mat).

  • Espectro de Frequência (FFT - Transformada Rápida de Fourier): Decompõe a onda temporal complexa em suas frequências componentes (Hz). Permite correlacionar os picos de vibração com as frequências geométricas de defeito (BPFI, BPFO, BSF, FTF) para apontar a origem da falha.
  • Demodulação por Envelope (Análise de Impactos): Aplica a Transformada de Hilbert para remover as frequências de ressonância estrutural e isolar os impactos puramente mecânicos repetitivos. É uma ferramenta poderosa para o diagnóstico preciso de defeitos em estágios iniciais.

🛠️ Arquitetura do Projeto

A arquitetura combina uma API para receber os dados em formato JSON e armazenar em um banco de dados para exibição, e entrada para um arquivo .mat, que é processado no servidor e tem as métricas enviadas para exibição.
